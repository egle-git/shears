Introduction
============

This directory contains BonzaiMaker codes supporting the old Boabab and Bonzai formats used for 8 TeV W+jet and Z+jet analyses (Run-1 format) and conversion to Run-2 format. In Run-1 format, Boabab and Bonzai uses different tree branch names. Run-1 format Baobab were produced with Pedro da Silva et al.'s ntuplizer and Bonzais with the BonzaiMaker located in OldOld directory from ULB (T. Seva, A. Leonard, and others).

Folder Content
==============

*OldOld* BonzaiMaker used for 8 TeV analyses. It produces Bonzais in the Run-1 format from Baobabs in Run-1 format.

*OldNew* BonzaiMaker producing Bonzais in Run-2 format from Baobab in Run-1 format
