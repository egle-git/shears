The directory contains the CMSSW patches required in addition to the Tupel code in order to produce Boabab ntuples.


CMSSW_7_6_3_patch2-mod.tgz
----------------------------

This file contains two modified CMSSW packages provided by JetMET and EG POGs, RecoJets/JetProducers EgammaAnalysis/ElectronTools, required to produce Boabab ntuples from miniaod 76x using CMSSW_7_6_3_patch2 with electron and photon energy correction and with jet pileup id recalulcation.
